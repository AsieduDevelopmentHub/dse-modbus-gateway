# Design principles

1. **Precise** — clear hierarchy, tabular numeric data, restrained chrome.
2. **Intelligent** — show operational meaning, not decorative tech motifs.
3. **Dependable** — high contrast, obvious status, no fragile visual gimmicks.
4. **Progressive** — modern enterprise software without startup clichés.
5. **Confident** — graphite / navy / warm white, copper used sparingly.

Avoid: purple AI gradients, neon glow, circuit-board wallpaper, excessive glassmorphism, invented logos.
